## 11. 长文本与切分测试

### 11.1 段落一

在 Markdown 切分测试中，长段落是检验分块算法的重要素材。一个优秀的分块策略应当能够识别语义边界，例如标题、段落、列表、代码块等，而不是简单地在固定字符数处截断。本段文字旨在提供足够长的连续文本，以便观察切分工具是否会在句子中间断开，或者是否能够保留完整的语义单元。我们重复一些内容来增加长度：Markdown 是一种轻量级标记语言，它允许人们使用易读易写的纯文本格式编写文档，然后转换成有效的 HTML 文档。Markdown 由 John Gruber 于 2004 年创造，如今已成为世界上最流行的标记语言之一。它的设计哲学是“易读易写”，让文档在源文本状态下也具有可读性。

### 11.2 段落二

分块（chunking）是构建检索增强生成（RAG）系统时的关键步骤。常见的分块方法包括固定大小分块、基于句子的分块、基于段落的分块、递归分块等。对于 Markdown 文档，理想的分块应该尊重文档结构：每个标题及其下属内容可以作为一个块，代码块和表格不应被拆分，列表项应保持完整。本段继续填充文字，以确保总长度足够触发分块逻辑。我们还可以加入一些重复的句子来增加 token 数量：Markdown 支持多种扩展语法，如表格、脚注、任务列表、数学公式等。不同的解析器对这些扩展的支持程度不同，因此测试文档需要覆盖尽可能多的语法变体。

### 11.3 段落三

在实际应用中，分块大小通常根据嵌入模型的上下文窗口来确定。例如，对于 512 token 的模型，块大小可能在 200-400 token 之间，并保留一定的重叠。重叠有助于保持上下文连贯性，避免因截断而丢失信息。本段继续提供文本，以便测试工具如何处理长段落。我们还可以加入一些特殊字符：!@#$%^&\*()\_+-=[]{}|;':",.<>/?`~，以及 Unicode 字符：你好，世界！こんにちは、世界！안녕하세요, 세계! 🌍🚀。
